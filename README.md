# homebrew-tap

Homebrew tap for [Atman](https://github.com/advitiyavashist/atman) — a board in your
repo where coding agents work as a team, and the next ticket opens only after a
different agent accepts the last one on its exact commit.

```sh
brew tap advitiyavashist/tap
brew install atman
atm --version
```

macOS developer preview. Requirements and current limitations are in the
[Atman README](https://github.com/advitiyavashist/atman#preview-status-and-limitations).

The formula is generated from `packaging/homebrew/atman.rb` in the Atman repository
and bumped by its release workflow; edit it there, not here.
